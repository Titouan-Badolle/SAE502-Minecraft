Infrastructure Minecraft automatisée
====================================

Déploiement par Ansible d'un serveur PaperMC avec proxy Nginx, base MariaDB,
supervision Prometheus/Grafana et sauvegardes restaurables, sur une VM Ubuntu 26.04.
